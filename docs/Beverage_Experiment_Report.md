# BeverageTown 競價模擬實驗報告
## 可口可樂 vs 百事可樂：價格衝擊、交叉彈性與 LLM 策略演化

> 執行日期：2025-08 · 引擎：`competeai/scene/beverage.py`（DeepSeek `deepseek-chat` 品牌 Agent + 參數化消費者）· 完整設計見 `docs/Beverage_Experiment_Design.md`
>
> 📖 **覺得這份太硬？請看白話版**：`docs/Beverage_Experiment_Report_白話版.md`（用故事與比喻解釋所有發現）

## 摘要

本實驗在 CompeteAI 框架下模擬可口可樂與百事可樂的雙寡頭競價，共執行 **480 runs**（9 cells × 6 組 × 5 seeds 的 LLM 主實驗 270 runs + sum 規則對照 30 runs + 純參數對照組 180 runs）。主要發現：

| 指標 | 模擬結果 | 實證錨點 | 評估 |
| :--- | :--- | :--- | :--- |
| PED（可口可樂自有價格彈性） | **−2.83**（log-log） | −2.0 ~ −4.0 | ✅ 範圍內 |
| XED 純參數（可樂→百事） | **+0.82 ~ +0.93**（弧彈性） | ≈ +0.63 | 略高（+0.2~0.3） |
| XED 含 LLM 回應 | **+0.41**（log-log） | — | LLM 百事回應吸收部分衝擊 |
| 2022 案例外部效度（百事 +12%） | 可樂市占 **+3.7 ~ +4.1pp** | ~ +2pp（6 個月） | 方向正確、量級略高 |
| 百事策略 | **100% 份額掠奪**（45/45 runs） | doc 預測兩策略分化 | 單一策略收斂 |
| 群體 vs 單人 XED | 群體 **0.82–0.92** > 單人 **0.59–0.63** | doc：群體 0.8–1.3 > 單人 0.2–0.4 | ✅ 方向一致 |
| 品質演化（SYM 組） | 0.86 → **1.38–1.50** | CompeteAI 品質提升 86.67% | ✅ 強烈提升 |

**核心結論**：① 參數化消費者層標定後，PED 落在實證區間、XED 在 +0.6~0.9 量級；② LLM 百事 Agent 對任何幅度漲價都以「降價 + 行銷」掠奪回應（$1.57–1.67），導致 HHI 上升至 0.55+ 的單極化市場；③ 群體消費者的社交決策顯著放大交叉彈性，與文獻預測一致；④ 對稱競價下雙方陷入品質軍備競賽。

## 1. 實驗設計回顧

- **兩階段**：Phase A 單邊衝擊（CG / TG1 +5% / TG2 +10% / TG3 +20%）、Phase B 對稱競價（SYM）、外部效度（PEP12 百事 +12%）。
- **純參數對照**（BF / BF5 / BF10 / BF20）：兩家價格皆固定，零 LLM——提供乾淨的替代效應測量與外部效度基線。
- **網格**：消費者 {100, 200, 300} × 時長 {2, 4, 6 週}；每 cell × 每組 × 5 seeds。
- **品牌**：LLM（DeepSeek `deepseek-chat`，每日 1 call，中文 prompt + 英文 JSON 鍵）；動作空間 = price / marketing_budget / recipe_change / slogan。
- **消費者**：參數化效用 `U = β − α·P + γ_q·Q + γ_a·A + Gumbel(2.0)`，30% 單人 / 70% 群體（多數決 + 探索傾向 0.1493），可 opt-out。
- **標定**：`alpha_scale=31000, beta_mean=5.0, beta_sd=3.0, gumbel=2.0` → 標定 PED=−2.01、XED=+0.66（多 seed 平均），參數凍結於全部 treatment。

## 2. XED 與 PED 測量（RQ1）

### 2.1 log-log 需求迴歸（Phase A：CG+TG1-3，4320 obs，seed 固定效果）

| 彈性 | 估計 | SE | 說明 |
| :--- | :--- | :--- | :--- |
| PED(可口可樂) | **−2.834** | 0.110 | 可樂需求對自身價格的反應 |
| XED(百事→可樂) | +0.940 | 0.068 | 百事漲價 → 可樂需求增加 |
| XED(可樂→百事) | **+0.411** | 0.107 | 可樂漲價 → 百事需求增加 |
| PED(百事) | −0.628 | 0.065 | 百事 LLM 自主定價下的自身彈性 |

識別策略：可樂價格為外生分組變數（group 內恆定），故不設 group 固定效果（與 P_coke 共線）；XED/PED 由**組間價格變異**識別，百事品質/行銷為時變控制變數。

### 2.2 弧彈性（Q10b）

**含 LLM 回應（CG vs TG）**：

| 組 | 可樂價格 | 百事市占（CG→TG） | 弧 XED |
| :--- | :--- | :--- | :--- |
| TG1 (+5%) | $2.10 | 0.514 → 0.502 | +0.282 |
| TG2 (+10%) | $2.20 | 0.514 → 0.496 | +0.145 |
| TG3 (+20%) | $2.40 | 0.514 → 0.501 | +0.148 |

**純參數（BF 系列，百事固定 $2.00）**：

| 組 | 百事市占（BF→TG） | 弧 XED |
| :--- | :--- | :--- |
| BF5 (+5%) | 0.534 → 0.510 | **+0.820** |
| BF10 (+10%) | 0.534 → 0.486 | **+0.934** |
| BF20 (+20%) | 0.534 → 0.458 | **+0.904** |

> **解讀**：純參數 XED（+0.8~0.9）高於實證錨點 +0.63，但方向與量級合理；加入 LLM 百事回應後表觀 XED 降至 +0.15~0.28（弧）/ +0.41（迴歸）——**LLM 百事的降價掠奪主動吸收了可樂漲價的替代衝擊**，使市場表觀替代性減弱。這是「策略回應稀釋交叉彈性」的直接證據。

## 3. 2022 案例外部效度（RQ5 / Q10c）

以 BF（兩家固定 $2.00）為基線，比較 PEP12（百事固定 +12% = $2.24、可樂 $2.00）：

| 消費者數 | 可樂市占（BF） | 可樂市占（PEP12） | Δ（pp） |
| :--- | :--- | :--- | :--- |
| 100 | 0.382 | 0.419 | **+3.67** |
| 200 | 0.364 | 0.401 | **+3.67** |
| 300 | 0.361 | 0.403 | **+4.12** |

> 模擬顯示百事漲 12% 後可樂奪回 **~3.7–4.1pp** 市占（6 週內）。2022 年實證為 6 個月內約 +2pp。方向正確、量級偏高——合理解釋：① 模擬僅 4–6 週、消費者無長期習慣慣性；② 模型無品牌資產/通路契約摩擦；③ 純效用替代在短窗內反應更強。

## 4. 策略演化（RQ2）：百事 LLM 的單一策略收斂

在全部 **45 個 TG 組 runs**（3 衝擊幅度 × 3 cells × 5 seeds）中，百事 LLM Agent **100% 採取「份額掠奪」**（降價 + 行銷投入），**從未出現「邊際跟進」**：

| 組 | 百事基準價 | 衝擊後百事價 | 百事行銷投入 |
| :--- | :--- | :--- | :--- |
| CG | $2.00 | $1.57（全期） | $410/日 |
| TG1 (+5%) | $2.00 | $1.59 | $415/日 |
| TG2 (+10%) | $2.00 | $1.63 | $468/日 |
| TG3 (+20%) | $2.00 | $1.67 | $402/日 |

**價格反應時序**（見 `fig/coke_pepsi_pepsi_price.png`）：衝擊日當天百事即降價至 ~$1.9，隨後數日持續下探至 $1.55–1.70，並同步加碼行銷。

> **解讀與討論**：doc 預測百事會分化出「份額掠奪」與「邊際跟進」兩種策略（後者於第 7 天跟漲至 $2.10）。實測結果百事一致選擇掠奪。可能原因：① LLM 在「對手已漲價 → 我方降價搶單」的框架下偏好進攻性策略，策略空間探索不足；② 消費者對價格高度敏感（PED −2.8），降價的市占收益遠大於跟漲的毛利收益——在效用模型下掠奪確為理性最優；③ 行銷投入回報（γ_a=0.8）使「降價+行銷」組合更強。**這說明 LLM Agent 能在給定市場結構下收斂到主導策略，但未必能展現文獻假設的策略多樣性。**

## 5. 對稱競價動態（RQ4 / Phase B）

SYM 組（兩家第 5 天起完全自由）：

- **價格戰**：可樂均價 $1.42、百事均價 $1.42（兩家皆大幅低於 $2.00 基線）——雙方陷入持續降價的囚徒困境。
- **品質軍備競賽**：品質從基準 0.70 → 0.86（第 5 天）→ **1.38–1.50**（末期），兩家同步拉升，呼應 CompeteAI 的品質提升理論（86.67% 發生率）。
- **HHI**：SYM 組 0.472，高於純參數雙寡頭（0.346）——掠奪性降價使市場向百事傾斜（可樂市占 0.27 vs 百事 0.52）。

## 6. 社交結構調節（RQ3）：群體放大 XED ✅

純參數 BF 系列的消費者層分析（252 萬筆逐日選擇軌跡）：

| 衝擊 | 單人 XED | 群體 XED |
| :--- | :--- | :--- |
| BF5 (+5%) | +0.629 | **+0.820** |
| BF10 (+10%) | +0.617 | **+0.915** |
| BF20 (+20%) | +0.593 | **+0.876** |

> 群體消費者的交叉彈性一致高於單人消費者（+0.2~0.3），方向與 doc 的預測（單人 0.2–0.4、群體 0.8–1.3）相符——群體的多數決 + 探索傾向放大價格傳導，印證「社交採購是價格衝擊傳導的槓桿」。

## 7. 群體決策規則對比（Q11）

anchor cell（n100_w4）弧 XED 對比：

| 衝擊 | majority_explore | sum（效用加總） |
| :--- | :--- | :--- |
| TG1 (+5%) | −1.25（噪音大） | +1.30 |
| TG2 (+10%) | −0.03 | +1.08 |
| TG3 (+20%) | −0.02 | +0.63 |

> sum 規則（理性共識）給出穩定、較高的 XED（0.63–1.30）；majority_explore 規則在 LLM 回應下波動大（多數決投票放大個體 Gumbel 噪音）。兩種規則的 XED 差異是消費者決策機制的敏感度證據——報告 XED 時須註明群體規則假設。

## 8. 規模與時間效應

| 消費者數 | 可樂市占 | 百事市占 | opt-out | HHI |
| :--- | :--- | :--- | :--- | :--- |
| 100 | 0.281 | 0.514 | 0.205 | 0.450 |
| 200 | 0.265 | 0.529 | 0.205 | 0.450 |
| 300 | 0.269 | 0.513 | 0.218 | 0.443 |

> 消費者數從 100→300 對市占/HHI 幾乎無影響（異質性隨樣本增加而平均化）——規模效應不顯著，100 人規模已足夠穩定。時間維度：品質與價格在 4–6 週持續演化未完全收斂，更長時窗可觀察均衡。

## 9. 轉移矩陣（Markov）

全樣本（LLM 組，日對日品牌轉移概率）：

| from \ to | 可樂 | 百事 | OptOut |
| :--- | :--- | :--- | :--- |

## 結論

1. **XED 測量可行**：純參數 XED +0.8~0.9、log-log PED −2.83 均貼近實證錨點，框架能產出有經濟意義的彈性估計。
2. **LLM 策略回應稀釋表觀彈性**：百事 LLM 的掠奪性降價使含回應的 XED 降至 +0.41——策略內生化後的「淨」交叉彈性低於純需求替代。
3. **外部效度通過**：百事 +12% → 可樂 +3.7~4.1pp，方向與 2022 實證一致（量級偏高，受限於模型無摩擦假設）。
4. **社交結構是價格傳導的放大鏡**：群體 XED > 單人 XED，與文獻預測一致。
5. **LLM 策略多樣性不足**：百事 100% 收斂於份額掠奪，未再現 doc 預測的雙策略分化——值得後續以不同溫度/角色設定/獎勵函數探索。

## 限制

- 消費者為參數化模型（無 LLM 語言化決策），社交討論簡化為多數決+探索。
- 品牌僅兩家、單一 SKU；無通路、庫存、季節性。
- LLM 策略對溫度與 prompt 敏感；單一溫度（0.7）下策略多樣性受限。
- 外部效度時間窗（4–6 週）短於實證的 6 個月。
